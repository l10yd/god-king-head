# ГОЛОВА БОГА-КОРОЛЯ

**Браузерная 3D-игра (WebGL2 + Three.js + TypeScript + Vite).**

Ты — крошечный астронавт, вечно падающий по фиксированной орбите вокруг
колоссальной парящей каменной головы Бога-Короля без шеи (масштаб 1 единица ≈ 1 метр;
голова ≈ 160 м в диаметре, орбита ≈ 240 м — лицо занимает полнеба). Собирай светящиеся души, уклоняйся от красных
духов-стервятников. **Первое** касание красного духа пробуждает голову:
веки открываются ≈ 8.5 секунд, затем Бог поворачивается к тебе и, если ты
задержишься в конусе его взора, испепеляет божественным лучом.

Никаких «победителей»: счёт-атака + выживание. Смерть → GAME OVER → мгновенный рестарт.

## Управление

| Клавиши | Действие |
|---|---|
| **WASD / стрелки** | полёт по орбите (вверх/вниз = к полюсам сферы) |
| **Shift** | ускорение (расходует синюю шкалу тяги) |
| **Пробел** | рывок-dash (короткий, с кулдауном) |
| **Колесо мыши** | зум камеры (от ~9 м до ~68 м за спиной); разблокируется после стартового раслёта |
| **P / Esc** | пауза |
| **H** | панель управления |
| **M** | звук вкл/выкл |
| **R** | рестарт |
| **F1 / ?debug=1** | debug-оверлей (FPS, три, вызовы, фазы) |

Камера — кинематографичный chase строго за спиной. Свободный обзор мышью
отключён (рожал петлю обратной связи с базисом движения); колесо крутит только
дистанцию. На старте рана камера стартует вплотную к игроку и за 2 секунды
разлетается до максимума (управление и зум возвращаются по окончании раслёта).

### 📱 Телефон / планшет

Автоматически включается сенсорное управление: **виртуальный стик** в левой
половине экрана (появляется там, где поставил палец); **отклонение до упора —
это SHIFT-ускорение** (тратит шкалу тяги). Справа — круглая кнопка **РЫВОК**
(эквивалент ПРОБЕЛА), кнопки **−/+** зума и **‖** пауза (заменяют колесо и ESC).
В `index.html` стоит `user-scalable=no` + `touch-action:none` — страница не
скроллится и не зумится пальцем. На десктопе слой не создаётся вообще
(в smoke проверяется отдельным тач-контекстом с реальными тапами).

## Механика душ

- **Синие** — очки (+100, крупные +250), растят комбо ×1…×5.
- **Золотые** — редкие, +1000 и **круговая волна**: испепеляет всех красных
  духов в радиусе 60 м (+75 за каждого).
- **Зелёные** — лечат скромно (+7 HP): это искры жизни, а не аптечки.
- **Красные духи-стервятники** — первое касание будит голову. Больше дух НЕ
  снимает HP: он **крадет тягу** — замедление и запрет Shift/рывка на 2.4 с,
  которых хватает, чтобы подставить тебя под взгляд. Духи постепенно учатся
  **преследовать** игрока в поле зрения (срывается рывком), а с собранными
  красными голова **вращается быстрее**.

## Запуск

```bash
npm install --ignore-scripts   # в песочнице Windows без postinstall
npm run dev                    # http://127.0.0.1:5199/
npm run build                  # продакшен-бандл в dist/
npm run preview                # локальный предпросмотр сборки
npm test                       # юнит-тесты (vitest, 47 шт.)
node scripts/smoke.mjs         # браузерный приёмочный прогон (см. ниже)
```

Сборка полностью процедурная: **ноль внешних ассетов** — геометрия головы
(≈ 24 проективных Gaussian-«черты» + эрозийный noise), все материалы
(GLSL-шейдеры камня/кожи/глаз/луча/душ), звуки (WebAudio: дрон, сердцебиение,
колокол пробуждения, луч, нойз-слои) генерируются в рантайме.

```

                      Difficulty · Awakening · Score (combo×5) · Health
  head/               HeadSculpt (форма лица) · HeadParts (веки/венец) ·
                      GodHead (риг глаз/век) · HeadTracking · BeamSystem
  player/             PlayerController (движение по сфере) · Player (модель)
  souls/              Soul · SoulField (пулинг мешей, ИИ духов)

  debug-page.mjs      диагностика загрузки/консоли
```

## Приёмочный прогон (scripts/smoke.mjs)

Автоматически в реальном браузере: интро (голова видна) → старт → орбита с 4 сторон и
полюсов → движение WASD-вводом → касание духа → **пробуждение** (8.5 с, веки > 0.7) →
gaze **AWARENESS→LOCK→CHARGE→FIRE** → урон лучом → **escape** из-под луча →
смерть → экран GAME OVER → рестарт со сбросом. Плюс пиксельные проверки яркости кадров
и захват всех console/page-ошибок. Текущий статус: **40/40 PASS, консоль чистая**
(включая мобильный тач-контекст: реальный тап по старту, стик-драг = буст, кнопка рывка).
(проверялось на софт-рендерере SwiftShader; на GPU — цель 60 fps).

## Качество

Пресеты LOW/MEDIUM/HIGH/ULTRA (pixel ratio, bloom, число частиц/звёзд) — в шестерёнках
интро. Настройки живут в localStorage. Пространство: ~162 KB gzip JS, старт мгновенный.

## Отладочные хуки (`window.__GK`)

`debugPeek()`, `debugStartRun(seed)`, `debugTeleport(θ,φ)`, `debugFaceGaze()`,
`debugSpiritNearPlayer()`, `debugGoldNearPlayer()`, `debugRedsRing(n,dist)`,
`debugKill()`, `debugHeal()`, `debugPlayerDir()` — используются smoke-тестами
и полезны вручную из консоли. В `debugPeek()` добавлены `cursed`, `curseTimer`,
`reds` (живых красных) для проверки проклятия и золотой волны.
